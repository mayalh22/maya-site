# maya-site

cleaner personal website / updated mayalh22.github.io
I used Next.js and a single CSS file. My site has pages for writing, art, photos, code projects, a timeline.resume, my favorite things, and my contact info.
The app directory has every page, with pages also for header, sections, spinnning stars, and grids as components. Styles/components.css controls the all of the visuals, including colors, spacing, fonts, borders, shadows, and animations.
